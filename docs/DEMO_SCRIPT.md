# ANNA CYCLE: 5-minute demo script

Everything is sample data. Say so first: "All listings and hubs are sample data, and nothing is a real result."
Use the "Viewing as" dropdown at the top to switch people. It is a demo view, not a login.

1. **The problem (30 s).** Landing page. "Every batch of produce deserves a next step."
2. **Buyer: marketplace (60 s).** View as *Local Wholesaler*. Marketplace, filter by Root vegetables, open the 100 kg tomatoes:
   75 kg reserved, 25 left. Ask for 30 kg and show the error. Reserve 25 kg.
3. **Vendor: split batch (45 s).** View as *Anwar*. Open the tomatoes: see who reserved what, confirm a request.
   Point out that quantities can never go over 100 kg.
4. **Vendor: no buyer, so storage (60 s).** Recovery options for the brinjal or spinach: suggestions with the reason for each,
   and the blocked ones with why. Open a hub, request a booking for 3 days and show the "at most 2 days" message.
5. **Food safety (30 s).** List a batch with condition "Poor". Recovery options: sale, storage and partner routes are blocked.
6. **Operator (45 s).** View as *Hub Operator*. Batches: accept the request, check in with an inspection, release.
7. **Impact (30 s).** Impact page: separate steps, "Sample data" and "Estimate" badges, listed is not saved food.
8. **Language (15 s).** Switch to Bengali with the language button.

## What to say about limits (honest)
- Rule-based, no AI. Storage guidance is not expert-reviewed. Bengali is a draft pending native review.
- In demo mode, sample data resets when the server restarts. Local mode has real accounts and saves to a file, but photo upload, password reset and a hub registration form are not built.
